# Technyong Workspace Snapshot

This folder is a GitHub-safe snapshot of `/home/data/Technyong_workspace`.

Large generated files and local environment artifacts were intentionally excluded because they are not suitable for a normal GitHub repository:

- `.git` directories
- `.venv` directories
- cache directories
- `wandb`, `logs`, and `tmp`
- `outputs/checkpoints`
- model/checkpoint files such as `*.ckpt`, `*.pt`, `*.pth`, `*.safetensors`
- BEHAVIOR-1K datasets, eval logs, OmniGibson appdata, and large docs assets
- archive files such as `*.zip`, `*.tar`, `*.tgz`, and `*.7z`
- `Miniconda3-latest-Linux-x86_64.sh`

The original local workspace remains unchanged.
